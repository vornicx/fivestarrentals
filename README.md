# Five Star Rentals — Archic Concept

High-end interactive website concept for Five Star Rentals in Marbella and Puerto Banús.

## Included

- Premium responsive landing experience
- Filterable vehicle collection using Five Star Rentals' public fleet information
- Interactive vehicle detail views
- WhatsApp enquiry flow with car, location and dates prefilled
- Owner Control demo for fleet availability, enquiries and clients

## Run locally

```bash
npm install
npm run dev
```

The production concept is designed and developed by Archic.
